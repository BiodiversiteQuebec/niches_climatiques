3  Variables

3.1 Climat

La principale variable climatique utilisée est la température moyenne annuelle. Plusieurs autres variables climatiques sont disponibles, mais la pertinence de celles-ci sera déterminée lors des rencontres avec les experts.

3.2 Habitat

En général, les conditions climatiques ne sont pas les seuls éléments expliquant la distribution des espèces et pour ajouter du réalisme aux modèles de distribution, il est essentiel de tenir compte des variables autres que les variables climatiques. Pour cette raison, des variables d’habitat ont également été intégrées aux modèles. Toutefois, dans un contexte de changements climatiques et de distributions projetées, plusieurs variables pertinentes ont dues être éliminées. En effet, seules des variables d’habitats qui demeureront stables dans le temps vis-à-vis des changements climatiques ont été considérées. Par exemple, le relief et l’élévation ne changeront pas dans le temps avec les changements climatiques et peuvent donc être utilisés dans les modèles. D’autres variables comme le pourcentage de forêt feuillue n’ont pu être considérées puisque la composition des forêts est susceptible d’être affectée par les changements climatiques.

Dans certains cas, des variables ont été considérées comme demeurant stables dans le temps, bien qu’à long terme, les changements climatiques pourraient avoir un impact sur ces variables. Par exemple, les milieux humides pourraient être influencés par les changements climatiques, mais nous avons considéré que cette influence serait probablement faible sur les périodes de temps considérées pour les analyses. Il en va de même pour les milieux agricoles et urbains. Dans certains cas, le milieu forestier (indépendemment de la composition forestière) a été considéré comme étant stable dans le temps pour les espèces trouvées dans l’extrême sud du Québec. Pour ces espèces, l’extension anticipée de leur aire de répartition ne dépassera généralement pas la limite actuelle des milieux forestiers et on peut donc assumer que le fait de considérer la forêt comme un prédicteur ne provoquera pas une troncation dans les aires de répartition futures. La variable % de forêts a été créée en additionnant les pourcentages de recouvrement des différents types de milieux forestiers (feuillus, mixtes, conifériens, etc.)

Les différents types de tourbières ont également été additionnés pour former une seule variable étant donné que les types de précis de tourbières n’étaient pas disponibles pour l’ensemble des endroits désignés comme étant des tourbières

Certaines espèces de salamandres sont retrouvées uniquement au sud du Fleuve St-Laurent. Pour éviter que les modèles de distribution étendent leur distribution au nord du St-Laurent, une variable binaire a été introduite dans les analyses (nord du St-Laurent = 0, sud du St-Laurent = 1).
